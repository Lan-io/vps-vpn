## ⚠️ 真实存在的不足

### 1. 价格不算最低档

追求极致低价的话，LisaHost可能不是最优选。双ISP住宅IP产品月付¥68起，相比几十元的普通机房IP VPS确实偏高。不过这是IP属性差异带来的成本差距，并非溢价。

### 2. 偶发网络公告问题

英国机房曾因上游运营商收回IP段导致部分用户服务中断，后更换为Sky天空电讯住宅IP并补偿数倍使用时长。此类运营风险客观存在，但处理态度还算负责。

### 3. SSH端口随机化

新机器默认分配随机SSH端口（非22端口），旨在防止暴力破解并保持IP纯净度。新手需要到控制面板查看端口，略有使用门槛。

### 4. 美国移动方向偶有拥堵

38段和154段的ISP住宅IP，中国移动用户去程美国方向存在拥堵现象。电信和联通用户不受影响，移动用户建议选择70段/64段。
