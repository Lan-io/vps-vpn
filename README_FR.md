## ⚠️ Faiblesses réelles

### 1. Le prix n'est pas le plus bas

Si vous recherchez le prix le plus bas possible, LisaHost n'est peut-être pas le meilleur choix. Les produits à IP résidentielle double ISP commencent à ¥68/mois, ce qui est effectivement plus élevé que les VPS à IP de centre de données ordinaires à quelques dizaines de yuans. Cependant, il s'agit d'un écart de coût lié aux propriétés de l'IP, pas d'une surévaluation.

### 2. Problèmes de réseau occasionnels

Le centre de données britannique a connu des interruptions de service pour certains utilisateurs en raison du retrait de segments IP par l'opérateur en amont, puis a basculé vers une IP résidentielle Sky et compensé par plusieurs fois la durée d'utilisation. Ce type de risque opérationnel existe objectivement, mais l'approche de traitement a été relativement responsable.

### 3. Randomisation des ports SSH

Les nouvelles machines se voient attribuer par défaut des ports SSH aléatoires (autres que le port 22), dans le but d'empêcher les attaques par force brute et de maintenir la pureté de l'IP. Les débutants doivent consulter le panneau de contrôle pour trouver le port, ce qui présente un léger seuil d'utilisation.

### 4. Congestion occasionnelle sur la direction mobile américaine

Les IP résidentielles ISP des segments 38 et 154 présentent une congestion pour les utilisateurs China Mobile se dirigeant vers les États-Unis. Les utilisateurs Telecom et Unicom ne sont pas affectés ; les utilisateurs Mobile sont invités à choisir les segments 70 ou 64.
