## ⚠️ Desvantagens Reais que Existem

### 1. Preço Não é o Mais Baixo

Se você busca o preço mais baixo possível, a LisaHost pode não ser a melhor escolha. Produtos com IP residencial de duplo ISP custam a partir de ¥68/mês, o que é de fato mais alto que VPS comuns de datacenter que custam algumas dezenas de yuan. Mas essa é uma diferença de custo trazida pela diferença de atributo do IP, não sobrepreço.

### 2. Problemas Ocasionais de Anúncios de Rede

O datacenter do Reino Unido já teve interrupções parciais de serviço para alguns usuários porque o operador upstream recolheu uma faixa de IPs. Depois trocaram para IP residencial da Sky e compensaram com múltiplos tempos de uso. Esse risco operacional existe objetivamente, mas a atitude no tratamento foi responsável.

### 3. Porta SSH Aleatória

Novas máquinas recebem uma porta SSH aleatória por padrão (não a porta 22), visando evitar ataques de força bruta e manter a pureza do IP. Iniciantes precisam verificar a porta no painel de controle, o que apresenta uma pequena barreira de uso.

### 4. Congestionamento Ocorrente na Direção dos EUA para China Mobile

IPs residenciais ISP das faixas 38 e 154 têm congestionamento na rota de ida para os EUA para usuários da China Mobile. Usuários da Telecom e Unicom não são afetados — usuários Mobile são aconselhados a escolher faixas 70/64.
