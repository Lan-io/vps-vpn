## ⚠️ Реальные недостатки

### 1. Цена не самая низкая

Если вы ищете максимально низкую цену, LisaHost может быть не лучшим выбором. Продукты с резидентным IP с двойным ISP стоят от ¥68 в месяц, что действительно выше по сравнению с обычным VPS с IP дата-центра за несколько десятков юаней. Но это разница в стоимости, обусловленная различием IP-атрибутов, а не переплата.

### 2. Периодические проблемы, связанные с объявлениями о сетевых работах

В британском дата-центре однажды часть пользователей столкнулась с прерыванием обслуживания из-за того, что вышестоящий оператор отозвал IP-диапазон; после этого произошла замена на резидентный IP провайдера Sky с компенсацией в несколько раз больше использованного времени. Такие операционные риски объективно существуют, но подход к решению вопросов в целом ответственный.

### 3. Рандомизация порта SSH

На новых машинах по умолчанию назначается случайный порт SSH (не порт 22), это сделано для предотвращения brute-force атак и поддержания чистоты IP. Новичкам нужно зайти в панель управления, чтобы посмотреть порт, что создаёт небольшой порог входа.

### 4. Периодическая перегрузка на направлении к China Mobile (США)

У резидентных IP ISP в диапазонах 38 и 154 существует проблема перегрузки для пользователей China Mobile на направлении к США. Пользователи China Telecom и China Unicom это не затрагивает, пользователям China Mobile рекомендуется выбирать диапазоны 70/64.
