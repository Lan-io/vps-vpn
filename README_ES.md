## ⚠️ Deficiencias que existen de forma real

### 1. El precio no es el más bajo

Si buscas el precio más bajo posible, LisaHost puede no ser la opción óptima. Los productos de IP residencial con doble ISP comienzan desde ¥68/mes, lo cual es ciertamente más alto que los VPS de IP de centro de datos comunes que cuestan unas pocas decenas de yuanes. Sin embargo, esta diferencia de coste se debe a las diferencias en los atributos de IP, no a una sobreprecio.

### 2. Problemas ocasionales por anuncios de red

El centro de datos del Reino Unido sufrió interrupciones del servicio para algunos usuarios cuando su proveedor ascendente retiró rangos de IP. Posteriormente se cambió a IP residencial de Sky Television y se compensó con múltiples veces el tiempo de uso. Este tipo de riesgo operativo existe objetivamente, pero la actitud de gestión fue bastante responsable.

### 3. Aleatorización del puerto SSH

Las nuevas máquinas se configuran por defecto con un puerto SSH aleatorio (no el puerto 22), con el objetivo de prevenir ataques de fuerza bruta y mantener la pureza de la IP. Los principiantes necesitan ir al panel de control para ver el puerto, lo que supone una pequeña barrera de uso.

### 4. Congestión ocasional en la dirección de China Mobile hacia EE. UU.

Las IPs residenciales ISP en los segmentos 38 y 154 experimentan congestión para usuarios de China Mobile en la ruta hacia Estados Unidos. Los usuarios de China Telecom y China Unicom no se ven afectados; los usuarios de Mobile deben optar por los segmentos 70 o 64.
